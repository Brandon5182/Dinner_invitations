# Dinner Guest List Manager
<h2> Description </h2>
This project demonstrates the fundamentals of working with Python lists by creating and managing a dinner guest invitation list. The program stores guest names in a list, modifies the list by replacing and adding guests, and generates personalized invitation messages using string methods.

Throughout the project, core Python list operations such as indexing, updating elements, and inserting new items are practiced. The .title() string method is also used to properly format guest names before displaying invitations. The commented sections represent different stages of the exercise, showing how the guest list evolves as new requirements are introduced (such as inviting additional guests after finding a larger dinner table).

**Key Concepts Demonstrated**

- Creating and storing data in Python lists
- Accessing list elements by index
- Updating existing list items
- Inserting new elements at specific positions
- Formatting strings with the .title() method
- Printing personalized messages
- Understanding how lists change over time

**Skills Practiced**

- Python list manipulation
- Basic string formatting
- Working with variables
- Sequential program execution
- Reading and modifying existing code

**Purpose**

The purpose of this project is to strengthen foundational Python programming skills by practicing common list operations in a realistic scenario. It serves as an introductory exercise for understanding how to manage collections of data and generate dynamic output based on list contents.
